# Changelog

All notable changes to Moodle Deck Sync are documented here.

## 1.0.0 - 2026-08-03

- Initial App Store release candidate for the Collaborative Learning Spaces
  Nextcloud companion app.
- Adds signed Moodle webhook handling for course group and assignment sync
  flows.
- Adds Deck board provisioning, stack creation, board archiving, membership
  reconciliation, and bot-based Deck API access.
- Adds administrator settings, health checks, notifications, persistence
  migrations, and release quality tooling.
